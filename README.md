## 이 책에 관하여

이 교재는 대학원 「기록정보서비스론」 수업을 위해 주차별 강의 목차를 교재 수준으로 확장한 것입니다. 기록정보서비스의 이론적 기초(1~2장), 이용자 연구(3~4장), 참고봉사와 검색도구·접근 정책(5~7장), 디지털·데이터 환경의 서비스(9~11장), 서비스 프로토타이핑(12~13장), 아웃리치와 평가(14~15장)를 다루며, 8장은 전반부를 종합합니다.

각 장은 국내외 핵심 연구와 두 권의 부교재를 바탕으로 작성되었습니다. 첫째, 퓨(Mary Jo Pugh)의 SAA 기본서 『Providing Reference Services for Archives and Manuscripts』(2005)는 참고서비스의 정의와 구성 요소, 지적·법적·물리적 접근의 세 차원, 참고면담의 질의 협상 모델, 접근정책의 요소, 이용 평가 틀(Conway의 품질·가치·진정성)에 이르기까지 이 교재의 개념적 뼈대를 이룹니다(1·2·5·6·7·15장). 둘째, 램지 외 편저 『Working in the Archives』(2009)는 수사학·작문 연구자들이 쓴 아카이브 연구법 안내서로, 서비스를 '받는 쪽'인 이용자의 눈으로 탐색 여정·아키비스트와의 협업·검색도구·숨은 기록과 디지털 기록을 증언한다는 점에서 이 교재의 이용자 중심 관점을 보완하는 짝입니다(3·5·6·9장). 이 두 부교재 외에 로(Kathleen D. Roe)의 『Advocacy and Awareness for Archivists』(2019)를 14장에서 사용합니다.

## 교재 구성

15주 강의에 대응하는 15개 장과 서문으로 이루어집니다.

| 부 | 장 | 내용 |
| --- | --- | --- |
| 이론적 기초 | 1~2장 | 기록정보서비스의 개념, 접근의 세 차원, 패러다임 전환 |
| 이용자 연구 | 3~4장 | 이용자 유형과 정보요구, 조사방법론 |
| 접근의 설계 | 5~7장 | 참고봉사, 검색도구, 접근과 프라이버시 |
| 중간 종합 | 8장 | 전반부 개념 지도, 중간시험, 프로젝트 기획 점검 |
| 디지털·데이터 | 9~11장 | 디지털 아카이브 서비스, FAIR 원칙, 시맨틱 검색과 온톨로지 |
| 서비스 프로토타이핑 | 12~13장 | 생성형 AI 활용과 비판적 검토, 구현·검증·문서화 |
| 확장과 평가 | 14~15장 | 아웃리치와 전시, 서비스 평가 |
